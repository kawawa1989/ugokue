# PoC の数値目標（仮）

PoC で性能を判定するときの基準。状態は **仮**。PoC-01 の確認項目で人が合意したら「合意済み」に変え、合意した日付を書く。

| 項目 | 目標 | 判定に使う値 |
| --- | --- | --- |
| 対象PC（Windows） | CPU：Core i5 第10世代 / Ryzen 5 3600 相当以上、GPU：GeForce GTX 1660 相当以上、メモリ 16GB | — |
| 対象PC（Mac） | Apple M1 以降、メモリ 16GB | — |
| 配信解像度 | 1920×1080 | プレイヤーのウィンドウ解像度 |
| 描画 fps | 60fps | 計測 CSV の `average_fps` が 59 以上 |
| 1フレームの処理時間 | 16.7ms 以内 | 計測 CSV の `p95_frame_time_ms` が 16.7 以下、`p99_frame_time_ms` が 20 以下 |
| Unity 側の CPU 時間 | 16.7ms 以内 | 計測 CSV の `average_cpu_time_ms` が 16.7 以下 |
| 総遅延（iPhone の動き → Unity の画面） | 150ms 以内 | 総遅延を測るチケットで計測方法と合わせて決める |

## 判定の条件

- 計測は [性能の計測](performance-measurement.md) の手順で、30秒以上記録する。
- 起動直後のウォームアップ（既定 2 秒）は記録から除く。
- VSync は既定の設定（オン）のまま測る。60Hz のディスプレイでは、平均 fps の上限が 60 になる。
- 同じ条件で 3 回測り、もっとも悪い回の値で判定する。
