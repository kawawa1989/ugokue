# 0001 実行環境は Unity の自前ランタイムにする

- 状態：採用
- 日付：2026-10-27

## 背景

生成したアバターを配信で動かす実行環境が必要。候補は Live2D（Cubism）、Inochi2D、Unity での自前実装。

## 決定

Unity で 2.5D の自前ランタイムをフルスクラッチで作る。Live2D と Inochi2D はメインの要件から外す。

## 理由

- Live2D：モデルファイル（.moc3）は非公開形式で、変形データを外部から流し込む公式の手段がない。自動化はパーツ分けと見本画像までに留まり、リギングの大半が人手の作業になる。
- Inochi2D：形式は公開されており書き出しは可能だが、仕様が 1.0 前で変更される可能性があると明記されている。Unity で動かすランタイムもない。
- Unity：パーツ分けから変形・物理・表情まで全て自動化でき、OBS への出力や編集画面も同じ環境で作れる。

## 影響

- 中間形式は特定の実行環境に依存しない形で設計する。Inochi2D のノード・パラメータ・バインディングの組み立て方は設計の参考にする。
- Inochi2D への書き出しは、仕様が安定した後の任意の機能とする。
