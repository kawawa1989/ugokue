# 0002 開発言語は Python と C# にする

- 状態：採用
- 日付：2026-10-30

## 背景

AI 生成パイプラインと Unity ランタイムで、使う言語を決める必要がある。中間形式の読み書きや変形計算を共通化するため、Rust のライブラリにする案も検討した。

## 決定

- AI 生成パイプラインは Python で書く。
- Unity ランタイム、編集画面、nizima LIVE 連携は C# で書く。
- 中間形式の読み書きは両方の言語で実装し、往復テストで一致を確かめる。
- Rust は使わない。

## 理由

- 利用する AI モデル（See-through、ComfyUI、PyTorch など）は Python 向けに提供されている。
- Unity のスクリプトは C# で書く。
- Rust の共通ライブラリは二重実装をなくせるが、Python からは PyO3、Unity からはネイティブプラグインで呼ぶ必要があり、Windows と Mac（Intel / Apple Silicon）向けのビルドとデバッグが複雑になる。

## 影響

- 中間形式を変更するときは、Python と C# の両方を同じ PR で直す。
- Unity に依存しない処理（中間形式、補間計算、入力アダプターなど）は、Unity を使わない .NET ライブラリに分け、`dotnet test` で検証できるようにする。
