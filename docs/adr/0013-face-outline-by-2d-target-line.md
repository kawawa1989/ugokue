# 0013 斜めの顔の輪郭は、3D で回した輪郭を 2D の目標の線へ寄せて作る

- 状態：採用
- 日付：2026-10-31

## 背景

[ADR 0011](0011-face-rotation-by-head-3d-shape.md) の頭の3D形状だけで ±45° に回すと、輪郭が絵として不自然になった（#50）。レビュー役のエージェント（[ADR 0012](0012-agent-review-of-face-rotation.md)）と人の確認で、次の問題が繰り返し挙がった。

- 奥側の頬が、目尻からあご先まで一本の斜めの直線になり、頬骨のふくらみがない。顔が細く「シュッと」しすぎる。
- あご先が V 字に尖る。
- 手前側（頭の横が回ってくる側）の輪郭が、こめかみからあごの角まで直線で、そこで折れる。耳が輪郭から浮く。

断面の形（楕円、超楕円、前を平らにした板と角）を変えて直そうとした。目の釣り合いは直ったが、輪郭の形は残った。正面の絵の輪郭は、横の輪郭とあごの下へ回り込む線が混ざっている。行ごとの断面だけでは、それを回した形が、描き手が斜めの顔に描く線にならない。

## 決定

1. 3D の回転と投影はそのまま使い（目・鼻・口の動き、奥の目の縮み）、顔の輪郭だけを、行ごとの 2D の目標の線へ寄せる。
2. 目標の線は、顔の層の左右の端を 3D で回した線（基の線）から作る。
   - 縦にならして、角と短い直線をなくす。
   - 口の高さより下は、あごの角からあご先へ回り込む楕円の弧に近づける（U 字のあご）。
   - 奥側には、頬の高さでいちばん強い頬のふくらみを足す。
   - 手前側には、正面の絵に描かれていない頭の横の張りを足す。
3. 目標 − 基 を、その側の輪郭の近くの頂点に、輪郭からの距離で弱めて足す。輪郭の外の髪にも足す。耳は、手前側では、目標の線からの離れ方を正面のまま保つ。
4. 手前側は、中心から半幅の 0.3 倍より外を、板の上の比から輪郭で比 1 へ、比がなめらかに変わる曲線で並べ直す。頭の横が回ってきて広がるぶんを範囲の中ほどに散らし、輪郭に描かれた線は太らせない。
5. 顔と髪の移動量は、輪郭（描かれている部分の境）とその外を守りながら、描かれている部分の内側だけを1回ならす。
6. 三角形の裏返りを解き直すときは、裏返った三角形の近く（頭の半径の 0.6 倍）だけを変え、離れた所の動きは守る。
7. ならす幅、頬のふくらみ、あごの丸み、頭の横の張りは、イラストごとの値（`params.json`）で変えられるようにする。

## 理由

- 輪郭は絵の印象を大きく決めるのに、3D の断面からは間接的にしか決まらない。目標の線にすれば、直したい形（ふくらみ、U 字、張り）を直接、値で書ける。レビュー役が描く修正の線との距離も、同じ線で測れる。
- 3D をやめて輪郭をすべて 2D で作る方法は、目・鼻・口との位置関係が崩れやすいので選ばなかった。
- 断面の形を超楕円や深い角にする方法も試した。中心のパーツが動きすぎるか、輪郭がほとんど変わらなかった。
- 前は、裏返りの解き直しがメッシュ全体をならしていた。これが輪郭の近くの伸びを散らしていたが、手前の輪郭も約 10 画素内へ引き込み、耳が浮く原因になっていた。解き直しを近くだけにすると、伸び（描かれている三角形の 99 パーセンタイルで 3 倍超）と、輪郭の線のにじみ、縁の階段が見えるようになった。そこで、ならしと裏返りの解き直しを分け、ならしは輪郭を守って内側だけにした。
- 手前側の頭の横が広がるのは、立体としては正しい。ただし、正面の絵にはその部分が細い帯しか描かれていないので、帯を引き伸ばすことになる。帯の外端（輪郭の線）は伸ばさず、中ほどで伸ばす。

## 影響

- `turn` は、輪郭の目標の線の値（`HeadParams`）を受け取る。値を渡さなければ、今までどおり 3D だけで作る（固定テストモデルとの一致のテストはこちら）。
- 目標の線は、正面の顔の層の端から作るので、顔の層の端が髪などで欠けると、目標の線もずれる。
- 頭の横の張りは、正面の絵に描かれていない部分を、顔の層の縁を引き伸ばして描く。張りを大きくすると、輪郭の線が太って見える。
