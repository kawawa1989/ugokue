# 0011 顔の向きのキーフォームは、頭の3D形状を回して投影して作る

- 状態：採用
- 日付：2026-10-31

## 背景

PoC-10 では、顔の向きのキーフォームを、生成した向きの絵との対応（特徴点、オプティカルフロー）と層の奥行きから推定した（[ADR 0009](0009-keyform-estimation-with-landmarks-flow-and-depth.md)）。人の確認を重ねるたびに奥行きの決め方を足したが、左右に回したときにパーツが平面的に変形して見えた。原因は次のとおり（#39）。

- 頭の形がなめらかなドームだけで、鼻の突き出しやあごの出っ張りがない。
- パーツごとに奥行きの決め方がばらばらだった。左右と上下で前面の深さも違った。
- 位置の取り方が混ざっていた。横は回転、縦は生成した絵の特徴点から取り、生成した絵の対応点も弱く引いていた。
- 生成した横向きの絵は、指定した角度より横顔に近く、正解として当てにならない。

[ADR 0010](0010-defer-per-vertex-depth-ordering.md) で、前後関係は描画順とビューの切り替えのままにし、頭の3D形状は絵を作る段階で使うと決めた。

## 決定

1. 顔の向きのキーフォームは、頭の3D形状と、パーツごとの付き方から、1つの回転（yaw → pitch）と正射影で作る。生成した向きの絵は、比較シートに並べる確認用にだけ使う。
2. 頭の3D形状は、画面の行ごとの楕円の断面（中心、半幅、前面の奥行き）で表すテンプレートにする。半幅と中心は、顔の層（髪の下に補完された頭皮を含む）の行ごとの幅から取る。前面の奥行きは半幅の 0.8 倍にする。口より下は、口の行の幅のままのあごの板にし、奥行きをあご先の値（頭の半径の 0.55 倍）へ近づける。
3. パーツの付き方は役割で決める。

   | 付き方 | パーツ |
   | --- | --- |
   | 表面 | 顔 |
   | 表面から浮かせて、形をなめらかにし、縮み方を 0.6 倍に弱める | 目、まぶた、眉、口、鼻（浮きが大きい）、眼鏡 |
   | 殻（断面を太らせた表面） | 前髪、頭の飾り |
   | 板（輪郭の外は頭の中心の面） | 耳、顔の横に垂れる髪 |
   | 奥の板 | 後ろ髪 |
   | 頭に一部だけ追従 | 首 |

4. 向いた側の輪郭は、回した形の外形線（断面がいちばん外に出る点）に合わせ直す。断面の点の角度を、輪郭から外形線の点までの範囲に詰める。
5. 左右は ±45°（15° おき）、上下は ±20° の格子で作る。上下は角度の 0.6 倍だけ回す。左右は頭の中心より奥の軸（首の付け根）で回す。
6. 中間形式は変えない。3D座標は持たせず、`AngleX` の範囲を格子に合わせて広げるだけにする。
7. ADR 0009 の推定（`estimate_keyforms`）は、固定テストモデルとの比較のために残すが、`ugokue-pipeline keyforms` では使わない。

## 理由

- **1つの式にする：** パーツごとに違う奥行きや位置の取り方を混ぜると、パーツどうしの位置関係が角度によって食い違う。共通の形と1つの回転にすれば、目・鼻・口・輪郭・髪の動きがそろう。
- **行ごとの楕円の断面：** 顔の層の形に正面でぴったり合い、0° の見た目が変わらない。断面の幅と奥行きを分けて持てるので、あごや頭頂など、場所ごとの深さを決めやすい。横顔の外形線で正中線の奥行きを補正する次の段階（#41）も、行ごとの奥行きを直すだけで済む。
- **輪郭の合わせ直し：** 2D の顔の輪郭は、立体の表面に描かれた固定の線ではなく、その向きから見た外形である。輪郭の頂点を表面の点として回すと、向いた側の頬が外形線の内側へ折り返す。外形線に合わせ直すと、向いた側の頬は外形線まで縮み、あご先は向いた側へ寄る。
- **あごを板にする：** あごの輪郭（V 字）は、横の輪郭ではなく、あごの下側へ回り込む線である。行ごとの幅で断面を作ると、輪郭の上で奥行きが急に 0 になり、上を向いたときにあごの輪郭がぎざぎざになった。
- **目・眉・口の形をなめらかにする：** まつ毛の目尻は顔の輪郭の外に出るので、表面の奥行きをそのまま使うと、回したときに三角形が裏返る（PoC-10 で見つかった問題）。2次式で近似すると、目尻の側ほど縮む向きは保ったまま、急な変化がなくなる。縮み方を弱めるのは、表面どおりだと奥の黒目が縦の細い線まで縮むため（PoC-10 の人の確認）。
- **目のくぼみを入れない：** 目の位置を中心にくぼみを入れると、奥の目が目尻の側より目頭の側で縮むようになった。
- **鼻はパーツ全体を前へ出す：** 鼻先だけを突き出すと、鼻の線が極端に縮んだ。
- **上下を弱める：** 頭の前面が深いので、角度どおりに回すと、顔が上下に大きくずれて首やあごの下が見えすぎた。
- **テンプレートを使う：** 奥行き推定のモデルや画像から3Dを作るモデル（#42）は、隠れた層の奥行きがわからない、正面と一致しない、毎回結果が変わる、という問題がある。テンプレートなら、結果が決まり、テストで確かめられる。

## 影響

- 生成した向きの絵は、キーフォームの計算に使わない。PoC-09 の生成は、確認用の比較シートのためだけに使う。
- AI が作るモデルの `AngleX` の範囲は ±45 になる。トラッキングの値はモデルの範囲に収めるので、入力アダプターは変えない。
- 首のメッシュも顔の向きのキーフォームグループを持つ。
- 横向きで見えるはずの耳の側面や、向いた側の頬の向こう側は、2D の変形だけでは出せない。必要かどうかは人の確認で判断する。
