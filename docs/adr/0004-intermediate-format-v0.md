# 0004 中間形式 v0 の構造

- 状態：提案
- 日付：2026-10-31

## 背景

AI 生成パイプライン（Python）と Unity ランタイム（C#）の間で、モデルを受け渡す形式が必要になった。この形式は、PoC の手作りテストモデル（PoC-03）、変形と遮蔽の実装（PoC-04、PoC-05）、AI 生成の出力（PoC-08〜11）、MVP の編集画面の共通の土台になる。出力先は後から差し替えられるようにする（[#20](https://github.com/kawawa1989/ugokue/issues/20)）。

## 決定

[中間形式 v0](../spec/intermediate-format.md) を次の方針で定める。

1. **フォルダ＋JSON＋PNG：** 1モデルを1フォルダで表し、`model.json` とテクスチャの PNG を置く。
2. **厳密なスキーマ：** JSON Schema で未定義の項目を禁止し、意味的な規則（参照の整合、格子の網羅など）は検証ツールで確かめる。形を変えるときは MINOR を上げる。
3. **座標はキャンバスのピクセル、y は下向き：** 画像処理側の座標系に合わせ、Unity 側で反転する。
4. **角度は度で、AngleX = yaw、AngleY = pitch：** 生成した絵の角度と、パラメータの値を同じ単位で扱う。
5. **連続的な変形と、切り替わる情報を分ける：** 頂点の動きはキーフォーム（Deformation）で補間する。メッシュの差し替え、表示・非表示、描画順はビュー（View）ごとに持ち、最も近いビューのものを使う。
6. **キーフォームは加算合成：** 1つのメッシュに複数のキーフォームグループを置ける。各グループは少数のパラメータの格子で基準からの移動量を持ち、結果を足し合わせる。
7. **対応づけは実行時と分けて保存：** 特徴点と頂点の対応を、信頼度と手修正の印（`source`）付きで持つ。実行時の描画には使わない。
8. **物理とトラッキングは最小限：** 物理は「入力パラメータ → 振り子 → 出力パラメータ」、トラッキングはパラメータごとの平滑化だけを持つ。
9. **C# の JSON ライブラリは Newtonsoft.Json：** Unity 公式パッケージ `com.unity.nuget.newtonsoft-json` で入れ、.NET 側も同じバージョンを使う。

## 理由

- **フォルダ＋JSON＋PNG：** 差分が読めてレビューしやすく、Python と C# の両方で標準的に扱える。1ファイルにまとめた形式（zip やバイナリ）は、配布が必要になった段階でこのフォルダを包む形で追加できる。
- **厳密なスキーマ：** 生成側の書き間違いを読み込み時ではなく検証時に見つけられる。未知の項目を許すと、どちらの実装が正しいか判断できなくなる。
- **キーフォームの加算合成：** Live2D のように全パラメータの組み合わせ（例：角度 3×3 × まばたき 2 × 口 2）を1つの格子で持つと、組み合わせの数だけ絵の推定が必要になる。AI の推定は「角度による動き」「まばたきによる動き」を別々に求めるため、別々に持って足すほうが生成側に合う。組み合わせで形が変わる部分（例：横を向いたときの口の形）は、そのパラメータの組で格子を作れば表せる。
- **ビューの切り替え：** 横顔寄りの角度では、目や耳の見え方が変わり、1つのメッシュの補間では表せない（[#20](https://github.com/kawawa1989/ugokue/issues/20) の「角度による変形と中間形式」）。切り替わる情報だけを生成した絵の単位で持つと、生成結果との対応がわかりやすい。
- **Newtonsoft.Json：** Unity の `JsonUtility` は null、配列の配列、辞書を扱えない。`System.Text.Json` は Unity での公式な導入手段がない。Newtonsoft.Json は Unity 公式パッケージがあり、Unity に依存しない `com.ugokue.core` からも参照できる。

## 影響

- 生成パイプラインは、書き出したフォルダを検証ツールに通してから Unity に渡す。
- ビューの切り替えは不連続なため、切り替わる境界での見た目の破綻を抑える方法（位置合わせ、フェード）は PoC-05 以降で決め、必要ならこの形式に項目を追加する。
- 物理の計算方法、トラッキングの校正・上限・復帰は、それぞれを実装するチケットで形式に追加する。
- MVP の編集画面は、`source: "manual"` の値を再生成で上書きしないようにする。
